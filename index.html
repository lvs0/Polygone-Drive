Features

WHAT MAKES IT
DIFFERENT

◈

SHARD & DRIFT

Files are split using Shamir Secret Sharing (4-of-7 quorum). Each fragment is encrypted with ML-KEM-1024 before entering the DHT. No relay ever holds a complete piece.

⟳

VAPOR STREAMING

Don't wait for full reconstruction. The engine fetches shards in sliding windows — start watching a video before all fragments arrive. Zero memory spikes.

↗

PUBLIC VAPOR LINKS

One command generates a poly:// token. Self-contained, base64-encoded, holds everything needed to recover the file from the network. Share it anywhere.

How It Works

THE LIFECYCLE
OF A FILE

01

SHATTER

ML-KEM-1024 key exchange. File is fragmented into 7 shards using Shamir. 4 are enough to reconstruct.

02

DRIFT

Each shard is published to a different DHT sector. They travel different network paths. No correlation possible.

03

LINGER

Shards live temporarily on relay nodes. The map (.pgd) or a Vapor Link is the only way to find them.

04

VANISH

TTL expires. Shards are deleted from relays. The file has never fully existed anywhere. It only transited.
